# Misafir Terliği Gümrük İdaresi

Kapının önünde duran şey ayakkabı değil, sınır kapısıdır.

Bu depo, misafirin getirdiği terliği gümrükten geçirir. İçeride ev terliği vardır, dışarıda diplomasi vardır, antrede ise memur vardır. Memur sensin. Terlik de senin değil. Bu yüzden form doldurulur.

## Neden var

Çünkü biri «ben ayakkabıyla girerim» dedi, diğeri «terlikler karıştı» dedi, üçüncüsü çayı soğutmadan konuştu. Devlet bunun için kurulmamıştır ama bu idare kurulmuştur. ISO belgesi yoktur. Çay altlığı vardır.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Bağımlılık olsaydı terlik çifti olurdu, o da kaybolurdu.

```bash
python3 gumruk.py --sahip dayi --numara 43 --renk lacivert
python3 gumruk.py --sahip kayinvalid --numara 38 --renk pembe --cift
```

## Çıktı ne anlama gelir

- YEŞİL HAT: Terlik masumdur. Çay ikram edilir.
- SARI HAT: Topuk aşınmıştır. Ek beyan istenir.
- KIRMIZI HAT: Sol tek bulunmuştur. Diğer yarı kayınvalide çayı süresince aranır.
- EL KONULDU: Bu terlik misafir değil, evin gizli ortağıdır.

Skor, sahip-numara-renk üçlüsünün karmasından çıkar. Rastgele değildir; adaletsizdir, ama tekrarlanabilir adaletsizliktir. Tek terlik beyanı riski yükseltir. Çift beyanı hafifletir. Hayat da böyle değil mi, değil.

## Yasal uyarı

Bu idare hiçbir bakanlığa bağlı değildir. Bağlı olduğu tek yer paspasın sağ köşesidir. Patates içermez. Anlam içermesi zorunlu değildir.

Gizli dosya antrede, `antre/muhurlenmis-not.txt` altındadır. Açan, misafir sayılır.
